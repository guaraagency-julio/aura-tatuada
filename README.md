# Aura Tatuada Studio

Projeto autoral de site para o Aura Tatuada Studio, desenvolvido pela Guará Agency.

## Plano

- **Etapa 1:** estrutura, identidade visual, layout base responsivo e preparação de conteúdos.
- **Etapa 2:** movimentos de scroll, estrela, vegetação, franja, janela/galeria e cadarço.
- **Etapa 3:** refinamento, otimização, integração com contatos/mapa e publicação na Cloudflare.

**Status:** Etapa 1 em desenvolvimento. Ainda sem deploy de produção.

Referências de interação: https://vila-capininga.vercel.app/ e https://antimatter-studio.framer.website/.
